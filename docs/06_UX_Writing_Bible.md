# Porsion Studio UX Writing Bible

## Purpose

This document defines voice, tone, microcopy, content behavior, and AI-generated copy guardrails for the Porsion Studio frontend and admin surfaces.

## Status

Draft scaffold.

## Contents To Define

- Brand voice
- Tone rules
- Navigation labels
- CTA language
- Product copy rules
- Empty states
- Error messages
- Form helper text
- Checkout copy
- Delivery and returns copy
- Account and security copy
- Marketing landing page copy
- Faris voice rules
- Laaj voice rules
- Bangla and English copy strategy
- AI-generated copy approval rules

## Core Rule

Copy must feel calm, premium, clear, human, and trustworthy. Never use loud marketplace pressure unless a campaign explicitly requires urgency.
