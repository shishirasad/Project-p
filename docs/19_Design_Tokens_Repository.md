# Porsion Studio Design Tokens Repository

## Purpose

This document defines how design tokens are named, stored, versioned, exported, and consumed across code, Storybook, design tools, and future AI Builder workflows.

## Status

Draft scaffold.

## Core Rule

Tokens are the shared language between design and code. Brand variation must come from tokens and context, not duplicated components.
